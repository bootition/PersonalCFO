# 用户决策清单

> 自动化能完成的已全部完成；以下事项需要用户提供数据或定性决策。
> 逐条给数/给口径后，由 AI 落地为分录/规则/配置。**涉及具体人与金额的明细在本地文件
> `docs/本地待办_DO_NOT_COMMIT.md`（不入库），本清单只列类别与问法。**

## 1. 期初建账（P1.5，最高优先级——财报自洽的前置）

盘点**建账日**（建议 2025-08-01，与账单起点对齐）各账户余额，差额进 `Equity:期初调整`：

| 科目 | 在哪看 | 需要的信息 |
|---|---|---|
| Assets:现金:支付宝 / 余额宝 | 支付宝 App | 2025-08-01 余额（找不到精确值就给现在值+说明） |
| Assets:现金:微信 / 零钱通 | 微信 App | 同上 |
| Assets:银行存款:各行 | 各银行 App | 活期余额 |
| Liabilities:花呗 | 支付宝-花呗 | 待还总额（记负数） |
| Assets:投资:* | 各平台 | 成本价口径（基金持仓成本/BUFF 饰品成本/虚拟币成本） |
| Assets:固定资产:* | 线下 | 大件历史原价（电子设备/家居/交通工具/房产） |
| Assets:预付账款:房租 | 租房合同 | 已预付未摊销部分 |

→ 把数字给 AI，生成 `journals/2025-opening.journal`（模板见 `config/科目表草案.md`）。

## 2. 定期规则（P1.6）

| 项 | 需要的信息 |
|---|---|
| 工资计提 | 月薪（税前/税后口径任选）、发放日、是否五险一金自付（裁决：社保不入表，给税后到手数即可） |
| 房租摊销 | 月租、付款节奏（月付/季付/年付）、每次付款日 |
| 固定资产折旧 | 每项资产：原价、启用月、折旧年限（电子设备 3 年？家居 5 年？） |

→ AI 写入 `journals/recurring.journal`（`~ monthly` 规则），forecast 自动生效。

## 5. Wealthfolio（P2.1/2.2）

1. 安装官方 Windows 版；
2. 建 4 个账户：**哈利布朗 / 攒股收息 / 虚拟货币 / CS饰品**（名称须与 `src/sync_fair_value.py` 的 ACCOUNT_MAP 一致）；
3. Transactions 模式录期初持仓与历史交易；
4. 配置目标（应急金、攒股目标）与再平衡阈值；FIRE 模块不用管；
5. 导出一次 holdings CSV 放 `raw/`，AI 验证字段并首跑 `sync_fair_value.py`。
