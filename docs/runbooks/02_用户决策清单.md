# 用户决策清单

> 自动化能完成的已全部完成；以下事项需要用户提供数据或定性决策。
> 逐条给数/给口径后，由 AI 落地为分录/规则/配置。**涉及具体人与金额的明细在本地文件
> `docs/本地待办_DO_NOT_COMMIT.md`（不入库），本清单只列类别与问法。**

## 1. 期初建账（P1.5，最高优先级——财报自洽的前置）

**只需两步**：
1. 按 `config/opening_balances.yaml`（已生成模板，仅本地）注释，把建账日（建议 2025-08-01，与账单起点对齐）各账户真实余额填上——支付宝/余额宝/微信/零钱通（各 App）、银行卡活期（各银行 App）、花呗待还（负数）、投资成本、固定资产历史原价、预付房租、借出款项。
2. 运行 `venv/Scripts/python src/opening_entry.py --date 2025-08-01`

→ 自动生成期初分录（差额进 `Equity:期初调整`）并校验平衡。找不到建账日精确值就给当前值+说明。

## 2. 定期规则（P1.6）

**只需两步**：
1. 按 `config/recurring_rules.yaml`（已生成模板，仅本地）填：月工资（税后到手数，社保不入表——既定裁决）、月房租摊销额、固定资产清单（原价/启用年月/折旧年限）。
2. 运行 `venv/Scripts/python src/gen_recurring.py`

→ 自动生成 `journals/recurring.journal`（`~ monthly` 工资计提/房租摊销/折旧），forecast 自动生效。就业后改工资数重跑即可（`--force`）。
