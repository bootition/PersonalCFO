# 从零到第一份财报

面向**第一次使用**的人。不需要懂会计，不需要懂命令行（只有准备环境时敲一次）。

预计：环境 5 分钟 + 走完向导 20~40 分钟。

---

## 第 0 步：准备环境（只做一次）

1. 安装 [Python 3.11+](https://www.python.org/downloads/windows/)
   —— 安装界面里**一定要勾选 `Add python.exe to PATH`**。
2. 打开 PowerShell（开始菜单搜索 "PowerShell"），`cd` 到项目目录，运行：

   ```powershell
   powershell -ExecutionPolicy Bypass -File scripts\bootstrap.ps1
   ```

   它会：建虚拟环境 → 装依赖 → 下载 hledger / deg → 生成配置。
3. 还需要 `vendor\paisa\paisa.exe`（界面程序）。见 [`tools/README.md`](../tools/README.md#paisaexe-从哪来)。

**验证一下**：

```powershell
venv\Scripts\python.exe src\finance.py check
```

账本还是空的，看到 `journals/ 下没有 .journal 文件` 是正常的。

## 第 1 步：启动界面

双击根目录的 **`启动PersonalCFO.bat`**。它会先同步账本，然后打开浏览器到 `http://localhost:6500`。

> 窗口别关 —— 关掉窗口服务就停了。

第一次打开，界面会显示「欢迎使用 PersonalCFO / 你的账本还是空的 / 开始初始化」。

## 第 2 步：上传账单（向导第 ① 步）

在手机 App 里导出账单，然后**直接拖进页面**（可多选、可分批）：

| 来源 | 怎么导出 | 格式 |
|---|---|---|
| 支付宝 | App → 我的 → 账单 → 右上角 → 开具交易流水证明 → 选时间段 → 发送到邮箱 | CSV（**必须是 CSV，不是 PDF**） |
| 微信 | App → 我 → 服务 → 钱包 → 账单 → 常见问题 → 下载账单 → 用于个人对账 | XLSX |
| 花呗 | 支付宝 App → 花呗 → 我的账单 → 开具结清证明 / 账单证明 | 加密 PDF（**要填打开密码**） |
| 银行 | 网上银行 → 交易明细 → 导出 | CSV / XLS / XLSX |

**导出时间段建议一开始就导**「你想开始记账的月份 → 今天」的完整区间，一次到位。

上传后会自动导入，页面会显示各来源进了多少笔。

> 银行明细如果要自动路由，**文件名里要带银行名**：`建行` / `招行` / `工商银行` 等。
> 三家（建行 / 招行 / 工行）开箱即用；光大需手工转换。
> 首次导入银行账单会**全部落到 FIXME**（程序不猜科目），按第 4 步补规则。

## 第 3 步：期初余额（向导第 ② 步）

**这一步最重要，也最容易填错。**

程序会从你上传的账单里自动推导出用到的账户（支付宝余额、微信零钱、各银行卡、花呗……）。
你要做的是：**打开手机 App，照着当前余额抄一遍**。

几条规则：

- **日期**默认是今天，可以改。记不清某个时间点的历史余额？就填**现在**的余额，
  程序会按"从今天开始建账"处理。
- **欠款填负数**。花呗欠 300 → 填 `-300`；信用卡溢缴款（多还了）填正数。
  —— 表单标签上会写「（欠款填负数）」提醒你。
- **投资**：逐项填代码、数量、买入单价（成本），有当前市值也填上，差额自动进期初调整。
- **固定资产**：逐件填原价、购买日期、折旧年限，程序会**自动追溯历史折旧**并按月继续折。
- **其他科目**（纸币、贵金属、别人欠你的钱……）：点「添加科目」，
  科目名要写成 `Assets:现金:纸币` 这种**以 `Assets:` 或 `Liabilities:` 开头**的路径。

> ✅ 填错不会静默丢数据：非法行会**标红并阻止提交**，并告诉你怎么改。
> ✅ 中途可以点「保存草稿」，下次打开自动恢复。

填完点「生成/更新期初」。可以反复点——新增项会合并进去，**不会重复记账**。

## 第 4 步：定期规则（向导第 ③ 步，可跳过）

有就填，没有就跳过：

- **工资**：每月到手多少（税后）
- **房租**：每月摊多少
- **折旧**：已在第 ② 步登记固定资产时自动生成，这里不用重复填

## 第 5 步：同步并看首页（向导第 ④ 步）

点「同步到界面」。首页会出现 4 张卡：净资产 / 本月收入 / 本月支出 / 本月结余，
以及净资产走势图。

## 第 6 步：处理 FIXME（可选但推荐）

导入后一定会有一批交易**没被规则命中**，它们落在 `FIXME` 科目里。这不是 bug，
是**待定性队列**——程序宁可问你，也不乱猜。

```powershell
venv\Scripts\python.exe src\journal_stats.py journals\import-*.journal
```

会告诉你 FIXME 的笔数与金额占比。建议收敛到 **5% 以下**。

怎么补规则：见 **[import-rules.md](import-rules.md)**。

## 第 7 步：出第一份财报

界面里点「CFO 工具 → 生成财报」，或者：

```powershell
venv\Scripts\python.exe src\finance.py report 2026
```

产物在 `reports\2026\`，每期有 5 张表（CSV + HTML + PDF）。

> ⚠️ **期次早于建账日的报表会被自动跳过**，并明确告诉你原因。
> 例如建账日是 9 月 10 日，那么 2026 一季报 / 半年报就没有意义（那时还没建账），
> 程序只出三季报和年报。这是有意为之——见下面「为什么」。
>
> 想强制生成（只看流水口径）：加 `--allow-pre-opening`。

## 之后每个月做什么

见 **[runbooks/01_月度SOP.md](runbooks/01_月度SOP.md)**：导出新账单 → 丢进界面第 ① 步 →
处理 FIXME → 对账 → （季末）回写投资 + 结账 + 出财报。目标 30 分钟。

## 常见疑问

**Q：我需要懂会计吗？**
不需要。你只需要理解三件事：钱从哪来（收入）、花到哪去（费用）、现在有多少（资产 - 负债 = 净资产）。
报表由引擎算，不用你算。

**Q：为什么期初要填"现在的余额"而不是"开始记账那天的余额"？**
因为绝大多数人拿不到历史某天的余额。填现在的余额，等价于"从今天起建账"，
之后的账就是准的。历史期间的报表本来也不该有——见下面的说明。

**Q：为什么一季报是空的？**
因为建账日期晚于那个季度末。**时点报表（资产负债表）在"期末早于建账日"时算的是
未建账的净流量余额，数字没有意义**。程序宁可跳过并告诉你原因，也不给你一份看着像真的假报表。
如果你确实想看那段期间的现金流，用 `--allow-pre-opening`。

**Q：数据会上传吗？**
不会。见 [privacy.md](privacy.md)。

**Q：能记账本到另一台电脑吗？**
可以——账本是纯文本。把 `journals/` 复制过去即可。建议用 `scripts/backup.py` 加密备份。
