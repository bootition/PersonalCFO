# 文件契约

> 四组件咬合靠文件不靠代码（`docs/decisions/01_架构总纲_v3定稿.md` 附录 A4）。
> 本文件以**实测**为准记录各契约格式；任何格式变化先改本文件，再改读写它的代码。
> 红线：本文件只描述结构与字段，示例一律脱敏/虚构，禁止贴真实交易。

## C1 `journals/*.journal`（hledger journal，唯一会计真相）

- **写方**：deg（import-*）、split_huabei.py（花呗拆分）、sync_fair_value.py（季度回写）、手工（期初/调整）、Paisa 编辑器
- **读方**：hledger、finance.py、Paisa
- 编码 UTF-8；Windows 下必须经 finance.py（自动 `chcp 65001`）调用 hledger。
- 分录格式（ledger 风格，deg 实测输出）：

```
2025/08/05 * <交易对方> - <商品说明>
    ; category: "<交易分类>"
    ; method: "<支付方式，含卡尾号，如 中国XX银行储蓄卡(1234)>"
    ; orderId: "<订单号>"
    ; payTime: "2025-08-05 20:32:35 &#43;0800 CST"
    ; source: "支付宝"
    ; status: "交易成功"
    ; type: "<支出|收入|不计收支>"
    Expenses:FIXME      100.00 CNY
    Assets:银行存款:建设银行   - 100.00 CNY
```

- deg 会在文件头生成 `1970/01/01 * Open Balance` 全科目 0 余额段（冗余但无害）。
- 元数据注释（method/orderId/type 等）是 split_huabei.py 两级匹配的依据，**生成脚本不得剥离**。
- 金额负号写法：`- 100.00 CNY`（负号与数字间有空格，hledger 兼容）。

## C2 `config/*.yaml`（deg 规则）

- **写方**：我们；**读方**：deg（`translate -p <provider> -t ledger --config <yaml>`）
- 关键语义（实测验证后更新；当前存疑项见 `docs/STATUS.md` 缺口 1）：
  - 未命中规则时落 `defaultMinusAccount: Assets:FIXME` / `defaultPlusAccount: Expenses:FIXME`（FIXME=待确认队列，这是设计特性）。
  - method 规则注意子串误伤：`余额` 会命中 `余额宝`，须 `fullMatch: true`（`任务计划.md` 红线 4）。
  - 规则顺序与覆盖语义：以对 deg 源码/实测的结论为准，结论确定后回写本节。
- provider 现状：`alipay` `wechat` 已配；`ccb/icbc/cmb/ceb` 待真实银行明细到位后配置（P1.4 暂缓）。

## C3 花呗账单证明 PDF（split_huabei.py 输入）

- 路径与打开密码：见本地 `docs/本地敏感信息_DO_NOT_COMMIT.md`（不入库）。
- 结构（2026-09-06 实测，17 页）：2026-02 ~ 2026-09 八个 `YYYY年MM月_花呗账单` 分段；每行 = 时间（日期+跨行秒）、名称、状态、金额、手续费。
- 名称形态：常嵌美团 26 位单号（对应支付宝商家订单号）；`**单号XP...` 为脱敏单号；特殊行：`自动还款 -X`、`退款还款 -X`。
- 匹配策略：美团 26 位单号精确 > 日期+金额+名称模糊；未匹配 → FIXME 清单。
- **文件含身份证号，仅本地使用，勿提交、勿外发。**

## C4 Wealthfolio holdings.csv（sync_fair_value.py 输入，P2）

- 字段（调研核实）：market_value / cost_basis / unrealized_gain 等；回写脚本必须对字段名做**断言**，不符即报错而非猜（`任务计划.md` 红线 5）。
- 生成调整分录：借/贷 `Assets:投资:*`，对侧 `Income:投资损益:公允价值`。

## C5 财报 PDF/CSV（finance.py 输出）

- 输出到 `reports/<year>/`（不入主仓）：Q1/H1/Q3/AN 四期 × 五表（bs/is/cf/bse/结账快照）× txt+html+csv + 汇总 PDF（Edge headless）。
- 口径：累计（Q1=1-3月、H1=1-6月、Q3=1-9月、AN=全年）。
