## 仍然存在的诚实边界

1. **月度借贷恒等是"体检"而非"交叉验证"**：任何借贷平衡的账本恒为 0；真正有效的交叉验证是财年勾稽 + 跨源账户核对（已加）。脚本输出已如实标注样本量。
2. **e2e 英文扫描仍有理论盲区**：与用户数据完全同名的 UI 英文词可能被数据白名单掩盖（`UI_STRICT` 已覆盖 50 个常见 UI 词，但不可能穷举）。
3. **私有仓 `master` 分支目前是快照**：历史推送受限于本机 git-over-HTTPS 不稳定；完整历史由 release bundle 承载，恢复命令已实测可用。
4. **`vendor/paisa/.git` 仍是浅克隆**：不要从它直接 push；每次 fork 有改动后按 runbook 03 §7.2 刷新 bundle。
