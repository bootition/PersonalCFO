# P7.15 报表自洽复核报告（2026-09-12）

## 目的

验证 PersonalCFO 的账本与报表口径自洽：借贷恒等式、财年勾稽、期初分录，以及账本结构有效性。
对应未解决清单 **P3-6（报表自洽复核：资产=负债+权益）**。

## 方法

- 直接以 hledger（`tools/hledger-bin/hledger.exe`）读取 `paisa_test/all.journal`（含 5 个 include），
  不经过 Paisa 数据库，避免"用被检查对象验证自身"。
- 校验脚本：`scripts/reconcile-check.py`（可复跑，退出码 0/1）。
- 财年勾稽以 `GET /api/income_statement` 为对照；财年起始月取配置默认 4 月（key 形如 `2025 - 26`）。
- 明细（含本地金额）写在 `.planning/reconcile-report.json`，不进仓库。

## 结果

| 检查项 | 结果 | 证据 |
|---|---|---|
| hledger check（交易平衡 + 日期有序） | ✅ | `check balanced ordereddates` 退出码 0 |
| 月度借贷恒等：每月末 资产+负债+权益+收入+支出 = 0 | ✅ | 14 个月末，最大偏差 **0.00** |
| 财年 2025 - 26 勾稽（hledger vs API） | ✅ | 收入差 **0.00**，支出差 **0.00** |
| 财年 2026 - 27 勾稽（hledger vs API） | ✅ | 收入差 **0.00**，支出差 **0.00** |
| 期初分录自平衡 + 权益调整 = −(资产+负债) | ✅ | 合计 0.00，权益调整与应计数一致 |
| FIXME 规模（待用户定性） | ⚠️ 披露 | 2 个科目；占绝对余额口径 6.93%（详见本地报告） |

## 结论

- **资产 = 负债 + 权益** 在每个月末成立，财年报表与账本流水完全勾稽，期初分录自洽。
- 未发现口径性错误；剩余差异只来自 FIXME 待定性队列（用户批处理后自然收敛）。
- 本次复核未修改任何账本数据，仅读校验。

## 复现

```bash
# 1) 启动服务（供 API 对照；不需要前端）
./vendor/paisa/paisa.exe serve --config paisa_test/paisa.yaml
# 2) 运行复核
python scripts/reconcile-check.py
# 3) 明细
cat .planning/reconcile-report.json
```

局限：脚本以 CNY 单一商品为前提（当前账本仅 CNY）；如未来引入多币种投资估值，
需扩展为按 commodity 分别校验。
