# 科目表草案（hledger 用）

> 规则：英文根（Assets/Liabilities/Equity/Income/Expenses）由 hledger 用于报表归类；
> 叶子用中文便于阅读。hledger 在 Windows 下需要 UTF-8 代码页（脚本已自动 chcp 65001）。

## 资产 Assets
- Assets:现金:支付宝
- Assets:现金:余额宝（货币基金 → 现金等价物）
- Assets:现金:微信
- Assets:现金:零钱通（货币基金 → 现金等价物）
- Assets:现金:现金
- Assets:银行存款:建设银行 / 工商银行 / 招商银行 / 光大银行（按实际新增）
- Assets:应收账款:工资（工资月末计提）
- Assets:预付账款:房租（季度预付，按月摊销）
- Assets:投资:基金 / 股票 / 虚拟货币 / CS饰品
- Assets:固定资产:电子设备 / 家居家电 / 交通工具 / 房产
- Assets:累计折旧:…（备抵科目，贷方余额）
- Assets:借出款项
- Assets:FIXME（= 待确认队列：需要人工定性的资金流）

## 负债 Liabilities
- Liabilities:花呗
- Liabilities:信用卡:建设银行 / …（按实际卡新增）
- Liabilities:借款

## 权益 Equity
- Equity:期初余额
- Equity:留存收益（期末结转）
- Equity:期初调整（建账差额）

## 收入 Income
- Income:主营收入:工资
- Income:副业收入
- Income:利息收入
- Income:投资损益:已实现 / 公允价值
- Income:其他收入（红包、报销、生活费、中奖）

## 费用 Expenses
- Expenses:日常三餐
- Expenses:出行交通
- Expenses:书籍学习
- Expenses:日常娱乐
- Expenses:旅游
- Expenses:日常缴费
- Expenses:医疗健康
- Expenses:衣物用品
- Expenses:被坑智商税
- Expenses:突发消费
- Expenses:锻炼花费
- Expenses:副业成本
- Expenses:房租摊销
- Expenses:折旧
- Expenses:其他
- Expenses:FIXME（= 待确认队列：未分类消费）

## 期初建账分录模板（升级日盘点后录入）

```
YYYY-MM-DD * 期初余额
    Assets:现金:支付宝        <实际余额> CNY
    Assets:现金:余额宝        <实际余额> CNY
    Assets:现金:微信          <实际余额> CNY
    Assets:现金:零钱通        <实际余额> CNY
    Assets:银行存款:建设银行  <实际余额> CNY
    Assets:投资:基金          <成本> CNY
    Assets:固定资产:电子设备  <历史原价> CNY
    Liabilities:花呗          -<待还> CNY
    Liabilities:信用卡:建设银行 -<待还> CNY
    Equity:期初调整
```
