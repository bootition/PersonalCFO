# PII 门禁 · 专属词表（示例 / 占位）
#
# 用途：`scripts/scan-pii.py` 会读取 `config/pii-rules.local.txt`（不入库）中的词条，
#       扫描被跟踪文件与历史提交；命中即失败。
#
# 为什么要分两层：门禁脚本本身会提交到公开仓库，
#       如果把真实人名/机构名写进脚本，门禁就成了新的泄漏源。
#
# 使用步骤：
#   1. 复制本文件为 config/pii-rules.local.txt（已在 .gitignore 中）
#   2. 每行一条；`==>` 左侧是命中词，右侧是建议替换值（供 --fix / 历史重写用）
#   3. 只写「不该出现在公开仓库」的词：真实姓名、家属姓名、真实机构/商户名、
#      个人账户别名、本机用户名与目录名、邮箱前缀等
#   4. 不要写通用会计/资产类别词（如「股票」「基金」「虚拟货币」）——那些不是 PII
#
# 格式：
#   <命中词>                    仅报告
#   <命中词>==><替换值>          报告 + 提供替换建议
#
# 示例（下面全部是占位符，不是真实值）：
#   张三==><家人姓名>
#   某某科技有限公司==><公司名>
#   我的炒股账户==><账户别名>
#   C:\Users\somebody==><本地路径>
#   somebody@example.com==><邮箱>
